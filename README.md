# Aimxity

Настраиваемый игровой оверлей прицела для Windows на Electron.

## Запуск приложения

```bash
npm install
npm run desktop
```

## Сборка установщика Windows (.exe)

```bash
npm install
npm run dist:win
```

Готовый установщик появится в `dist/` с именем `Aimxity-Setup-1.0.0.exe`.

## Горячие клавиши

- `Ctrl + Shift + X` — показать / скрыть прицел.
- `Ctrl + Shift + H` — скрыть прицел.
- `Ctrl + Shift + +` — увеличить размер прицела.

Прицел отображается поверх окон и не перехватывает клики мыши. Некоторые игры и античиты могут блокировать сторонние оверлеи; соблюдайте правила конкретной игры.
