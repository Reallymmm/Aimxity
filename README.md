# Aimxity

Настраиваемый игровой оверлей прицела для Windows на Electron.

## Запуск приложения

```bash
npm install
npm run desktop
```

## Сборка установщика Windows (.exe)

```bash
npm install
npm run dist:win
```

Готовый установщик появится в `release/` с именем `Aimxity-Setup-1.0.0.exe`.

## Настройка

В приложении можно менять форму и цвет прицела, размер, длину классических линий, толщину, зазор, прозрачность и смещение по X/Y. Для тонкой настройки доступны числовые поля без заданного верхнего предела. Можно сохранять, применять и удалять профили, а горячие клавиши — переназначать в соответствующем разделе.

По умолчанию: `Ctrl + Alt + X` — показать/скрыть, `Ctrl + Alt + H` — скрыть, `Ctrl + Alt + ↑/↓` — изменить размер.


Прицел отображается поверх окон и не перехватывает клики мыши. Некоторые игры и античиты могут блокировать сторонние оверлеи; соблюдайте правила конкретной игры.
